Gérer le site

Les modifications sont enregistrées directement sur le site. Elles apparaissent en ligne environ une minute après l'enregistrement.

Connexion

Comment obtenir un jeton ?
  1. Sur github.com : photo de profil → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Repository access : « Only select repositories », puis choisis le dépôt du site.
  3. Permissions → Repository permissions → Contents : « Read and write ».
  4. Choisis une durée d'expiration, valide, et copie le jeton (il ne s'affiche qu'une fois).

Le jeton est comme un mot de passe : ne le partage pas. Ne coche « se souvenir » que sur un appareil personnel.
